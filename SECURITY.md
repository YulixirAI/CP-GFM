# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this repository,
please report it privately rather than opening a public issue.

Contact the repository owner directly. Include:

- a description of the issue and its potential impact;
- steps to reproduce, where feasible;
- the affected file(s) and version.

Do **not** include in a public report: private target names, candidate
sequences or structures, production paths or service names, or any material
outside this public interface.

## Scope

This repository contains only public interfaces, data contracts, documentation,
and a synthetic toy runtime. It does not contain the production implementation.
Security of the production system is out of scope for this repository.

## Supported versions

Only the latest tagged release of this public interface is supported.
